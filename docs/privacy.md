# Privacy

Open Indie Studio collects no analytics in v1.

The app stores the current project in the browser's IndexedDB on the user's device. Exported files are created locally through browser Blob downloads.

Optional local LLM assistance sends a prompt only to the endpoint the user enters in the UI, such as a locally running Ollama-compatible endpoint. No secret keys are requested or stored.
